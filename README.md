Students are required to develop a **Financial Dashboard** based on the provided sample code.

### 1. Single Asset Analysis (Stock, Bond, Bitcoin, etc.)

**[1] Summary**

* Display a summary dashboard for the selected asset.
* Allow users to select an asset from a list of global or Vietnamese stocks (or other supported financial assets).
* Present key information such as price and other essential financial indicators.

**[2] Chart**

* Display historical price and trading volume over a selected time period.
* Support different sampling intervals (daily, weekly, monthly, etc.).
* Provide multiple chart types, such as:

  * Line Chart
  * Candlestick Chart
  * Other appropriate visualizations

**[3] Statistics, Financials, and Analysis**

* Display statistical information, financial statements, and price analysis for the selected asset.
* Refer to the provided sample application as a guideline.

### 2. Portfolio Analysis

**[4] Portfolio Analysis**

* Implement portfolio analysis using financial models such as:

  * CAPM (Capital Asset Pricing Model)
  * APT (Arbitrage Pricing Theory)
  * Other relevant portfolio analysis methods
* Display corresponding charts, statistics, and investment performance metrics.

**[5] Monte Carlo Simulation**

* Implement Monte Carlo Simulation for investment forecasting and risk analysis.

### 3. AI Chatbot Support

* Integrate an AI chatbot to assist users with financial and investment-related questions.
